# VoiceType

Локальное распознавание речи для Windows: диктовка в любое окно по горячей клавише, длинные записи, файлы и YouTube-ролики. Работает на вашем компьютере, без облака, бесплатно и без лимитов.

Распознавание — [GigaAM v3](https://github.com/salute-developers/GigaAM) от Сбера, одна из самых точных открытых моделей для русского языка.

## Возможности

- **Диктовка.** Держите правый Ctrl в любом окне и говорите — текст вставится туда, где стоит курсор. Стили как в Wispr Flow: обычный, непринуждённый, очень непринуждённый.
- **Запись.** Говорите хоть час: текст распознаётся по ходу записи, аудиофайл не сохраняется. Пауза, живая аудиоволна, мини-плеер поверх окон.
- **Файлы.** Перетащите аудио или видео (mp3, m4a, wav, mp4, mkv, mov…) — получите текст любой длины.
- **YouTube.** Вставьте ссылку — текст возьмётся из субтитров ролика, без скачивания видео.
- **Чистая речь.** Убирает «э-э», «м-м», повторы и, по желанию, слова-паразиты.
- **Модель-редактор** (по желанию, 2,7 ГБ): небольшая нейросеть Qwen3-4B на вашей видеокарте исправляет английские названия («автор эффектс» → After Effects, «альт таб» → Alt+Tab), ошибки и пунктуацию. Ставится кнопкой в Настройках → Редактор.
- **Словарь замен** для терминов: «гитхаб» → GitHub.
- Интерфейс в стиле Notion, светлая и тёмная тема, русский и английский язык, масштаб Ctrl +/−.
- **Автообновление** с GitHub при запуске.

## Требования

- Windows 10 или 11, 64-бит
- Видеокарта NVIDIA (рекомендуется; без неё работает на процессоре, медленнее)
- ~7 ГБ свободного места, интернет на время установки

## Установка

1. Скачайте архив: **Code → Download ZIP** (или последний релиз справа в разделе *Releases*) и распакуйте в любую папку, например `D:\Program Files\VoiceType`. Лучше путь без кириллицы.
2. Запустите **`install.bat`** двойным кликом. Он сам скачает Python, PyTorch с CUDA и модель распознавания (~4 ГБ, 10–20 минут). Права администратора не нужны, всё ставится внутрь папки программы.
3. В конце на рабочем столе и в меню «Пуск» появится ярлык **VoiceType**, программа запустится сама.

Если Windows покажет SmartScreen — «Подробнее» → «Выполнить в любом случае».

## Обновления

Программа сама проверяет новые версии при запуске (Настройки → Обновления). Обновляются только файлы программы: ваши настройки, словарь, история диктовок и транскрипты не трогаются. После установки обновления в боковой панели появится кнопка «Перезапустить».

Если что-то пошло не так — запустите `update.bat`: он доставит библиотеки и перезапустит программу.

## Файлы

| Файл | Что это |
|---|---|
| `install.bat` | первая установка |
| `update.bat` | ручное обновление библиотек и перезапуск |
| `start.bat` | запуск |
| `start_debug.bat` | запуск с консолью, если нужно увидеть ошибки |
| `transcribe_files.bat` | перетащите на него файлы — получите .txt рядом |
| `logs/` | журнал работы |
